# Hangar

An all-in-one support toolbox for Windows: SQL Explorer, XML / JSON, Diff, Notes, Remote Desktop and API Explorer in
one window.

- **Download:** the [latest release](https://github.com/coetzerp001/Hangar-Releases/releases/latest) -
  `Hangar.exe` (64-bit) and `Hangar32.exe` (32-bit, for 32-bit ODBC drivers). Keep the two side by side; Hangar updates
  itself from this repository's releases (each with `SHA256SUMS.txt`).
- **Home page:** https://coetzerp001.github.io/Hangar-Releases/
- **Privacy policy:** https://coetzerp001.github.io/Hangar-Releases/privacy.html

This repository holds only the releases and these pages; Hangar's source is kept elsewhere.
