Hangar

An all-in-one support toolbox for Windows: one window, a rail of tools.

The tools

  • SQL Explorer - any ODBC database: tables, SQL editors, Insight, import and export, Ask Claude
  • XML / JSON - view as a tree, check, beautify or minify
  • Diff - two texts or files side by side, every difference marked
  • Notes - note cards and checklists: colours, labels, pin, search
  • Remote Desktop - your servers in groups, logins kept by name, sessions in tabs
  • API Explorer - collections, environments, scripts and tests

Sign in with Google

Signing in is optional. When you do, Hangar keeps your settings - saved connections, notes, Remote Desktop sites, API collections - in a hidden folder of your own Google Drive, so every computer you sign in on has the same. Hangar sees nothing else in your Drive, and passwords go there encrypted with a passphrase only you know. See the privacy policy.

Download

Hangar.exe (64-bit) and Hangar32.exe (32-bit, for 32-bit ODBC drivers) are on the releases page. Keep the two side by side; Hangar updates itself from there.
